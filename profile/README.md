## 📌 Visão Geral

O projeto **"Inovação em Gestão Pública da Tuberculose: Integração de
Inteligência Artificial e Visualização Territorial no SUS"** tem como
objetivo fortalecer a gestão pública da tuberculose por meio da
integração de Inteligência Artificial (IA), Machine Learning e
visualização territorial de dados no âmbito do Sistema Único de Saúde
(SUS).

A solução é estruturada em uma arquitetura moderna baseada em
microsserviços, promovendo escalabilidade, interoperabilidade e
segurança.

------------------------------------------------------------------------

# 🏗️ Arquitetura Técnica

A plataforma é baseada em **Arquitetura Orientada a Serviços (SOA /
Microsserviços)**, organizada nas seguintes frentes:

## 🔹 Backend -- Núcleo de Inteligência

-   Desenvolvido em **Python com FastAPI**
-   Execução de modelos de Machine Learning e IA Generativa
-   Processamento intensivo de dados
-   Integração com bases do SUS
-   Exposição de serviços via APIs REST

## 🔹 API Gateway -- Gerenciamento e Segurança

-   Desenvolvido em **Node.js com NestJS**
-   Autenticação via **JWT / OAuth**
-   Gerenciamento de login e cadastro
-   Controle de permissões e segurança

## 🔹 Frontend -- Interface do Usuário

-   Desenvolvido com **React.js e Next.js**
-   Dashboards interativos
-   Visualização territorial e epidemiológica
-   Interfaces Web e Mobile
-   Consumo das APIs REST

## 🔹 Ciência de Dados

-   Pipelines de ingestão e tratamento (ETL)
-   Engenharia de dados
-   Desenvolvimento de modelos preditivos e generativos

------------------------------------------------------------------------

# 🔗 Fontes de Dados e Integração

O projeto prioriza a interoperabilidade com sistemas nacionais e locais:

-   **SINAN** -- Vigilância epidemiológica
-   **e-SUS AB** -- Dados da Atenção Básica
-   **SIVEP** -- Monitoramento epidemiológico
-   **TBweb** -- Controle e acompanhamento da tuberculose
-   **Dataset HUJBB** -- Base do Complexo Hospitalar UFPA/Ebserh
